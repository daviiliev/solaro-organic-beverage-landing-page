# SOLARO — Organic Botanical Energy

Link to the landing page: https://daviiliev.github.io/solaro-organic-beverage-landing-page/

A premium landing page concept for SOLARO, a fictional organic beverage brand focused on botanical ingredients, natural flavors and energetic modern living.

## Overview

SOLARO combines organic ingredients with a vibrant, contemporary visual identity.

The website was designed as a complete digital brand experience rather than a simple product landing page, with a strong focus on product presentation, flavor discovery, interaction and motion.

## Features

- Premium beverage-focused landing page
- Realistic product presentation
- Interactive flavor collection
- Product-focused hero section
- Shopping cart interaction
- Ingredient storytelling
- Sustainability section
- Mixology section
- Brand story
- Store locator concept
- Newsletter interaction
- Responsive navigation
- Scroll-based animations
- Hover interactions
- Micro-interactions
- Responsive mobile layout

## Design

The visual identity combines:

- Solar yellow
- Fresh botanical green
- Energetic orange
- Warm cream
- Deep forest green

The typography uses Manrope throughout the interface, creating a clean and contemporary visual language.

## Technology

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Google Fonts
- Material Symbols
- Responsive design
- CSS animations and transitions
